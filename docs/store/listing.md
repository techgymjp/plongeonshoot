## 日本語

**アプリ名**（30 文字以内）

```
ムササビシュート ハンドボール
```

**簡単な説明**（80 文字以内）

```
サイドから跳び込み、空中で倒れ込んでキーパーを打ち抜け！ハンドボールのムササビシュートを再現した3Dゲーム。
```

**詳しい説明**

```
満員の室内アリーナ。ホイッスルが鳴り、味方からパスが来る。
サイドから中へ跳び込み、空中で大きく倒れ込んでシュートを放て！ハンドボールのサイドシュート「ムササビシュート（プロンジョン）」を3Dで再現。全20本で何点取れるかに挑戦しよう。

■ ホイッスルでパスを受ける
・右コーナー、サイドの定位置、サイドライン沿いの走り込みなど、毎回ちがう位置から始まる
・パスも直接パス、バウンドパス、山なりパスといろいろ
・選手は右利きの左サイド。画面の右側から攻める

■ 3歩以内に跳び込む
・歩数はボールを取ってから数える。4歩目はオーバーステップで反則
・6mラインを踏んだら反則。シュートの前に着地しても失敗
・「ダッシュ」を押している間は歩幅が大きくなり、スピードが上がる
・ボールを取ってからダッシュで2歩進むと「ムササビ」が使えるようになる

■ ムササビシュート
・ゴールではなくコートの中央へ向かって跳び、空中で倒れ込んでシュートの角度を広げる
・先に高く上がってキーパーの動きを見て、遅れて倒れ込むのが本物の動き
・着地は前に転がって受け身

■ 円形カーソルとボタンで、いろいろなシュート
・跳んだら左側の円形カーソルでコースを決める（高く／低く／左右）
・右側のボタン：中央ノーマル、上ループ、左右スピン、下バウンド
・投げる前には腕を振りかぶるので、少し時間がかかる
・地面ではステップシュート。跳んですぐならクイック、空中・倒れ込みながらのシュートも
・スピンはダッシュのスピードと使った歩数で大きく曲がる

■ キーパーは7タイプ
・定位置でじっくり型、飛び出し型、ニアを固める型、左右に揺さぶる型、フェイント型、ゴールライン型、大の字ジャンプ型
・シュートを打つ人に向かって前に出てくる。先に動いたら「右に倒れた！」などと表示される
・飛び出したらループ、大の字ならバウンド、倒れたら逆へノーマル。動きを見極めて打ち分けよう

■ 室内アリーナの3D
・満員のスタンド、広告ボード、実際のサイズのゴールとコート
・ゴールで大歓声と紙吹雪

■ かんたん操作
・自信がないときは「ナビ」をオンに。跳ぶタイミングや、ねらうコースを教えてくれる

■ その他
・S〜Dのランクとベスト記録
・スコアを友だちにシェア（ナビあり／なしも表示）
・決まらなかった1本は、広告を見てやり直せる（1ゲーム5回まで）
・オフラインでも遊べる（広告・シェアは通信が必要）
・日本語・英語対応

さあ、跳べ。20本全部、決められるか？
```
