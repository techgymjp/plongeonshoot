# ムササビシュート

ハンドボールの「ムササビシュート（プランジョンシュート）」をテーマにしたブラウザゲームです。
`index.html` をブラウザで開けばそのまま遊べます（ビルド不要・外部ライブラリなし）。

- 室内競技なのでホーンは鳴らさず、効果音は **歓声・拍手**（Web Audio で合成）
- ゴールすると花火ではなく **紙吹雪** が上がります
- プレイヤーは **右利き**（ボールは右手で持ち、右手から投げます）

## 遊び方

パスを受けた瞬間からスタートします。1ゲーム5本です。
開始地点（センター／左右45度／左右サイド／ロング）とキーパーのタイプは毎回ランダムです。

| 操作 | 内容 |
| --- | --- |
| 円の方向カーソル | 左右：走る方向とシュートのコース（左右）／上下：シュートの高さ（高・低） |
| ジャンプ | 走っている間はいつでも跳べる |
| ムササビ | 3歩ダッシュした時だけ出現。滞空時間がとても長い |
| ノーマル／ループ／スピン／バウンド | 着地するまでいつでも打てる |

### シュートの種類（ボタン × タイミング × 方向）

押すタイミング：

| シュート | 打ち方 | 倍率 |
| --- | --- | --- |
| ステップシュート | ジャンプせずに、走りながら打つ | ×1.0 |
| クイックシュート | ジャンプしてすぐ（0.24秒以内）に打つ | ×1.3 |
| ジャンプシュート | ジャンプの頂点あたりで打つ | ×1.2 |
| 倒れ込みシュート | 落ちながら打つ | ×1.1 |
| ムササビシュート | ムササビで跳んで打つ | ×2.0 |

ボタンの種類：

| ボタン | 球筋 | 基本点 |
| --- | --- | --- |
| ノーマル | 速い直球。方向カーソルの通りに飛ぶ | 100 |
| ループ | キーパーの頭上を越える山なりのボール | 150 |
| スピン | 床でバウンドした後に逆方向へ曲がる | 180 |
| バウンド | 床に当てて足元を抜く | 130 |

ゴールの隅（左右の端で高め／低め）に決めると +50、連続ゴールでボーナスが加算されます。

### 失敗になるとき

- 4歩目を踏む（オーバーステップ）
- 6mラインを踏む
- シュートを打つ前に着地する

### ゴールキーパー

キーパーはタイプ（定位置でじっくり型・前に飛び出す型・ニアを固める型・左右に揺さぶる型・ゴールライン型・大の字ジャンプ型）ごとに、立つ位置と動き方が違います。
シューターが空中にいる間、キーパーは先に動くことがあり、吹き出しで表示されます。

- 「前に出てきた！」「しゃがんだ！」 → ループ
- 「大の字ジャンプ！」 → バウンド・スピン
- 「左に倒れた！」「右に倒れた！」 → 逆サイドへノーマル

ムササビは滞空時間が長いので、キーパーが動いたのを見てから打ち分けられます。

### キーボード操作

| キー | 操作 |
| --- | --- |
| 矢印キー / WASD | 方向（↑高 ↓低） |
| Space | ジャンプ |
| Shift / M | ムササビ |
| Z / X / C / V（または 1〜4） | ノーマル / ループ / スピン / バウンド |

## ファイル構成

- `index.html` … 画面とボタン
- `style.css` … 見た目
- `game.js` … ゲーム本体（3D風の描画、選手とキーパーの動き、ボールの物理、サウンド、紙吹雪）

## Claude Code から GitHub にプッシュするための設定

Claude Code（claude.ai/code）でこのリポジトリにプッシュするには、Claude と GitHub の連携が必要です。
プッシュで `403` になる場合は、次のどちらかを行ってください。

1. **Claude GitHub App をリポジトリ（組織）にインストールする**
   https://github.com/apps/claude/installations/select_target
   （`techgymjp` 組織へのインストールには、組織オーナーの権限が必要です）
2. **claude.ai 側で GitHub を再接続する**
   https://claude.ai/customize/connectors?auth_start=github&auth_start_force=1
